## 主要变更

### 1. Vite 7 升级
- 要求 Node.js 20.19+ 或 22.12+
- 仅支持 ESM 格式
- 移除 Sass 遗留 API 支持
- 更新默认浏览器兼容性目标

### 2. ESLint 9 升级
- 使用新的扁平配置格式（eslint.config.mjs）
- 移除旧的 .eslintrc.cjs 配置
- 更新所有插件以支持新格式

### 3. Sass 语法更新
- 将 `@import` 替换为 `@use` 语法
- 使用现代 Sass API

### 4. TypeScript 类型修复
- 修复所有类型错误
- 更新类型定义
- 优化类型检查性能

### 5. UnoCSS 升级
- 升级到最新版本以支持 Vite 7
- 修复构建兼容性问题
